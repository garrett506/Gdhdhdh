# Telegram-бот «Слот на очки»

Развлекательный бот без денег: ежедневный бонус 500 очков, ставка 25 очков и настраиваемые вероятности.

## Запуск

1. Создай бота через `@BotFather` и скопируй токен.
2. Узнай свой числовой Telegram ID, например через `@userinfobot`.
3. Установи Python 3.11+ и зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Задай переменные и запусти:

   ```bash
   export BOT_TOKEN="токен"
   export ADMIN_IDS="123456789"
   python main.py
   ```

Для постоянной работы запускай на VPS через systemd или Docker.

## Команды игроков

- `/start` — правила
- `/daily` — 500 очков раз в календарные сутки по UTC
- `/spin` или отправка 🎰 через кнопку Telegram — прокрут за 25 очков
- `/balance` — баланс
- `/prizes` — открытые вероятности и выигрыши

## Начальные вероятности

| Результат | Выплата | Вероятность |
|---|---:|---:|
| Мимо | 0 | 58% |
| Возврат | 25 | 20% |
| Небольшой | 50 | 14% |
| Хороший | 100 | 6% |
| Крупный | 250 | 1,8% |
| Джекпот | 1000 | 0,2% |

Средняя выплата — 24,5 очка на ставку 25 (RTP 98%).

## Настройка

Администратор смотрит таблицу через `/admin_probs` и меняет несколько вероятностей одной командой, например `/setprobs 1=58 2=20 3=14 4=6 5=1.8 6=0.2`. Общая сумма должна быть ровно 100%. Также можно остановить бота и изменить `weight` в таблице `prizes` базы SQLite; 100 единиц веса = 1%.

Стандартный анимированный слот Telegram имеет серверный результат, которым бот управлять не может. Поэтому его картинка используется как анимация, а выплата независимо и прозрачно рассчитывается по таблице выше.

Очки нельзя покупать, продавать или выводить — это явно написано игрокам.
